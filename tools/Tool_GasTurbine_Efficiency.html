สภาวะบรรยากาศ (Ambient)
ข้อมูล: อุณหภูมิอากาศ ที่หน้า Compressor จริง (Compressor Inlet Temp — CTIM) ที่มา: DCS tag "Compressor Inlet Temp" หรือ sensor ที่ Bellmouth ⚠ ถ้ามี Evap Cooler/Fogging ต้องใช้ค่า "หลัง" ระบบลดอุณหภูมิ ไม่ใช่อุณหภูมิอากาศภายนอก | ISO: 15°C | ไทย: 28–38°C
barG: ระดับน้ำทะเล = 0.000 barG (= 1.013 barA)
ข้อมูล: ความดันบรรยากาศ (Barometric) ที่ไซต์ = ความดันสัมบูรณ์ขาเข้า Compressor ที่มา: Weather Station ของโรงไฟฟ้า / DCS / กรมอุตุฯ — ที่สูงจากระดับน้ำทะเลมาก ความดันจะต่ำลง (~−0.012 barA ต่อ 100 m)
ข้อมูล: ความชื้นสัมพัทธ์ที่หน้า Compressor ที่มา: Weather Station / DCS — หลัง Evap Cooler/Fogging อากาศจะเกือบอิ่มตัว (RH ~85–95%)
ระบบลดอุณหภูมิอากาศขาเข้า (Inlet Air Cooling)
ข้อมูล: มวลน้ำที่ระเหยกลายเป็นไอปนเข้าไปกับอากาศ (เฉพาะส่วนที่ระเหยจริง ไม่รวมน้ำทิ้ง Blowdown ของ Media) ที่มา: มิเตอร์น้ำป้อนระบบ Evap/Fogging − น้ำทิ้ง หรือประมาณจาก Δความชื้น: ṁ_spray ≈ ṁ_a × (ω₂−ω₁) — ทั่วไป ~0.5–1.5% ของ ṁ_a
⚖️ นิยามมวลของเครื่องมือนี้ (สำคัญเมื่อมีสเปรย์น้ำ):
• ṁ_a = อากาศชื้นแวดล้อม (อากาศแห้ง + ไอน้ำเดิม) ก่อนสเปรย์
• มวลผ่าน Compressor = ṁ_a + ṁ_spray
• มวลไอเสียออกกังหัน ṁ_g = ṁ_a + ṁ_spray + ṁ_fuel
• Chiller ลดอุณหภูมิอย่างเดียว ไม่เพิ่มมวลน้ำ (ṁ_spray = 0)
คอมเพรสเซอร์ (Compressor)
ข้อมูล: ความดันทางออกคอมเพรสเซอร์ (ก่อนเข้าห้องเผาไหม้) ที่มา: DCS tag "CDP / Compressor Discharge Pressure" หรือเกจที่ Discharge Casing ⛔ ไม่ใช่ความดันเชื้อเพลิง (Fuel Gas Pressure) และไม่ใช่ความดันไอเสีย
rₚ = P₂(abs) ÷ P₁(abs) = —
ข้อมูล: อัตราส่วนความดันสัมบูรณ์ (barA/barA) ของคอมเพรสเซอร์ ที่มา: Datasheet/OEM Spec ของรุ่นเครื่อง | Industrial GT: 10–35 | Aeroderivative/Modern: ถึง 45
ข้อมูล: ประสิทธิภาพไอเซนโทรปิกของคอมเพรสเซอร์ ที่มา: Performance Test ล่าสุด / OEM Curve — ไม่ทราบใช้ 82–88% (เครื่องเก่า/Fouled จะต่ำลง)
ข้อมูล: อัตราไหลเชิงมวลของอากาศชื้นแวดล้อม (ก่อนสเปรย์) เข้า Compressor ที่มา: DCS (คำนวณจาก Bellmouth ΔP) หรือ Datasheet — วัดตรงยาก ถ้าไม่มีค่า ใช้ตัวช่วยด้านล่าง
วัด ṁ_a ไม่ได้ → คำนวณย้อนจากค่าที่วัดง่ายกว่า
แก๊ส: kg/s = Nm³/h × ρ(≈0.7–0.8 kg/Nm³) ÷ 3600
ห้องเผาไหม้ (Combustor)
ข้อมูล: อุณหภูมิแก๊สร้อนขาเข้ากังหัน (Firing Temp) — ตัวกำหนดสมรรถนะหลัก ที่มา: Datasheet/OEM (มักไม่วัดตรงหน้างาน — DCS แสดงค่าคำนวณของ OEM) | Modern GT: 1200–1650°C
ข้อมูล: สัดส่วนความร้อนเชื้อเพลิงที่ปล่อยจริงในห้องเผาไหม้ ที่มา: OEM Spec — Natural Gas ทั่วไป 98–99.5% (ไม่ทราบใช้ 99)
ข้อมูล: ค่าความร้อนต่ำ (LHV) ของเชื้อเพลิง หน่วย kJ/kg ที่มา: ใบวิเคราะห์คุณภาพแก๊สรายเดือน (Gas Chromatograph) จาก ปตท./ผู้ขาย — ถ้าได้เป็น MJ/Nm³ ให้หาร ρ (kg/Nm³) ก่อน เช่น 38 MJ/Nm³ ÷ 0.76 = 50,000 kJ/kg
กังหันแก๊ส (Turbine Expander)
ข้อมูล: ประสิทธิภาพไอเซนโทรปิกของกังหัน ที่มา: Performance Test / OEM — หรือ back-calc จาก T₄ ไอเสียที่วัดได้ (ปรับ η_t จน T₄ คำนวณตรงกับ DCS) | ทั่วไป 85–92%
ข้อมูล: การสูญเสียเชิงกล Bearing + Gearbox ที่มา: OEM Spec (98–99.5%) — เครื่อง Direct Drive ไม่มี Gearbox ใช้ ~99.5%
ข้อมูล: ประสิทธิภาพ Generator ที่มา: Nameplate / Factory Test Certificate ของ Generator (96–99% ขึ้นกับ Load และ PF)
Regenerator / Recuperator (ถ้ามี)
ทั่วไป: 70–90% | เพิ่ม Thermal Eff. ~5–10%
ค่าพิกัด Design (เปรียบเทียบ)
ที่มา: Nameplate เครื่อง / สัญญาซื้อขายไฟ (PPA) / Commissioning Test Report — ระบุฐาน ISO หรือ Site Rating ให้ชัด
ที่มา: Datasheet/Commissioning (ฐาน LHV) — สัมพันธ์กัน: HR = 3600 ÷ η_th เช่น η 32% → 11,250 kJ/kWh
กำลังไฟฟ้าวัดได้ (Field Measurement)
วิธีที่ 2: วัด P_elec จาก kWh meter → คำนวณย้อนหา η_th
ข้อมูล: กำลังไฟฟ้า Gross ที่ขั้ว Generator ที่มา: kWh Meter / DCS / รายงานเดินเครื่องรายชั่วโมง ⚠ ระบุให้ชัดว่า Gross (ขั้ว Gen) หรือ Net (หัก Auxiliary) — เครื่องมือนี้เทียบกับ Gross

🔄 Brayton Cycle — Simple Cycle Gas Turbine
📐 Step-by-Step Calculation — Brayton Cycle
1State 1 — Compressor Inlet (Ambient)
Properties of Air at State 1
h₁ = Cp_air × T₁  (kJ/kg)  |  Cp_air ≈ 1.005 kJ/kg·K
T₁ = T_ambient (K) = T_amb(°C) + 273.15
ความหนาแน่น: ρ₁ = P₁/(R_air × T₁)  | R_air = 0.287 kJ/kg·K
2State 2 — Compressor Outlet (Actual)
Isentropic & Actual Compressor Work
T₂s = T₁ × rₚ^((γ-1)/γ)  | γ = 1.4, (γ-1)/γ = 0.2857
w_c,isen = Cp_air × (T₂s − T₁)  (kJ/kg)
η_c = w_c,isen / w_c,actual  →  w_c,actual = w_c,isen / η_c
T₂ = T₁ + w_c,actual / Cp_air
3State 3 — Turbine Inlet (Combustor Exit / TIT)
Heat Addition in Combustor
Cp_g ≈ 1.148 kJ/kg·K (hot gas, แก๊สเผาไหม้)
h₃ = Cp_g × T₃  (kJ/kg)
q_in = Cp_g × (T₃ − T₂)  [per kg air+fuel]
Fuel-Air Ratio: FAR = q_in / (η_cc × LHV)
4State 4 — Turbine Outlet (Exhaust)
Isentropic & Actual Turbine Work
γ_g = 1.333 (hot combustion gas)
T₄s = T₃ / rₚ^((γ_g−1)/γ_g)  | (γ_g−1)/γ_g = 0.25
w_t,isen = Cp_g × (T₃ − T₄s)
w_t,actual = η_t × w_t,isen  (Turbine Expander Work)
T₄ = T₃ − w_t,actual / Cp_g
5Net Work & Thermal Efficiency
Performance Metrics — ASME PTC 22
w_net = w_t,actual − w_c,actual  (kJ/kg air)
Back Work Ratio (BWR) = w_c,actual / w_t,actual × 100%
P_shaft = ṁ_air × w_net  (kW)
P_elec = P_shaft × η_mech × η_gen  (kW)
Q_in = ṁ_air × q_in  (kW)
η_th = P_elec / Q_in × 100%   [Thermal Efficiency]
Heat Rate = 3600 / η_th  (kJ/kWh)
ṁ_fuel = Q_in / (η_cc × LHV)  (kg/s)

🏁 Performance Summary
📋 สูตรอ้างอิง — Gas Turbine Thermodynamics
Brayton Cycle (Ideal — Air Standard)
η_Brayton,ideal = 1 − (1/rₚ)^((γ−1)/γ)
T₂s/T₁ = rₚ^((γ−1)/γ)
T₄s/T₃ = (1/rₚ)^((γ−1)/γ) = 1/rₚ^((γ−1)/γ)
Actual Cycle (ASME PTC 22 — Field Measurement)
η_c = (h₂s − h₁) / (h₂ − h₁) = Isentropic Comp. Efficiency
η_t = (h₃ − h₄) / (h₃ − h₄s) = Isentropic Turbine Efficiency
w_net = η_t × Cp_g × (T₃ − T₄s) − Cp_a × (T₂s − T₁)/η_c
Heat Rate & Efficiency Conversion
HR (kJ/kWh) = 3600 / η_th
HR (BTU/kWh) = 3412 / η_th
η_th = P_elec / Q_in = P_elec / (ṁ_f × LHV × η_cc)
Regenerative Cycle (Boyce, Ch.2)
ε_regen = (T₂r − T₂) / (T₄ − T₂)
T₂r = T₂ + ε_regen × (T₄ − T₂)  [Air preheated by exhaust]
q_in,regen = Cp_g × (T₃ − T₂r)  [Reduced fuel requirement]
η_th,regen = w_net / q_in,regen
Cp, γ Values Used (Boyce, Table 2-1)
Air (cold): Cp_a = 1.005 kJ/kg·K, γ = 1.400, (γ−1)/γ = 0.2857
Flue gas (hot): Cp_g = 1.148 kJ/kg·K, γ_g = 1.333, (γ−1)/γ = 0.250
R_air = 0.287 kJ/kg·K
Ref: Boyce, Gas Turbine Engineering Handbook, 4th Ed. (2012), Ch. 2–3
Ref: ASME PTC 22-2014, Gas Turbine Power Plants
Ambient Correction — ISO 3977 / ASME PTC 22
P_corr = P_meas × (P_ISO/P_site) × √(T_site/T_ISO)
T_ISO = 288.15 K (15°C), P_ISO = 1.01325 barA
η_th ไม่เปลี่ยนตาม Ambient (เป็น ratio) แต่ Power Output เปลี่ยน
