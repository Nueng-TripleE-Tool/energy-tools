คำนวณ Flash Steam ที่ควรเกิดตามธรรมชาติ

คอนเดนเสทร้อนที่ลดความดันลงจะระเหยตัวเองส่วนหนึ่งเสมอ — นี่คือของปกติ ไม่ใช่การรั่ว
ความดันไอน้ำก่อนดัก (bar g อ่านจากเกจใกล้ดัก/หัวจ่าย) — ทั่วไป 4–10 bar g; โปรแกรมบวก 1.013 เป็น bar abs
ความดันในท่อคอนเดนเสทหลังดัก (bar g) — ท่อเปิดสู่บรรยากาศ = 0, ระบบกลับแบบมีความดัน 0.3–2 bar g
อุณหภูมิคอนเดนเสทก่อนดักที่วัดจริง (°C, IR/เทอร์โมมิเตอร์สัมผัสท่อ) — ใส่ 0 ถ้าไม่ได้วัด (ถือว่าอิ่มตัว)
ใส่ 0 ในช่องอุณหภูมิถ้าไม่ได้วัด ระบบจะถือว่าคอนเดนเสทอยู่ที่จุดอิ่มตัวของความดันต้นน้ำ ถ้าวัดได้จริงให้ใส่ — คอนเดนเสทที่เย็นกว่าจุดอิ่มตัว (sub-cooled) จะให้ flash น้อยลงมาก

เทียบกับสิ่งที่เห็นหน้างาน

คำถามเดียวที่ตัดสินได้: ไอที่เห็นเป็นพวยต่อเนื่องแรง หรือเป็นกลุ่มขาวฟูแล้วจางหาย

อัตราการรั่วผ่านรูเปิด (สูตร Napier)

ขนาดรูเทียบเท่าของดักที่รั่วเปิดค้าง (mm) — ประเมินจากขนาด orifice ของดัก (datasheet) 2–6 mm
ความดันไอน้ำที่ดักตัวที่รั่ว (bar g) จากเกจสายนั้น
สัมประสิทธิ์การไหลผ่านรู — รูคม 0.6–0.7, ดักเสียเปิดค้างใช้ 0.7 (ค่าประมาณ Napier)
ต้นทุนไอน้ำต่อตัน (บาท) จากบัญชีต้นทุน = ค่าเชื้อเพลิง ÷ η หม้อไอน้ำ + น้ำ/เคมี; ชีวมวล 500–900, NG 900–1,300, น้ำมันเตา 1,200–1,600
ชั่วโมงที่ระบบไอน้ำมีความดันต่อปี (ชม./ปี) — ดักรั่วตลอดเวลาที่มีไอ; 3 กะ ≈ 7,000–8,000
Emission factor ต่อตันไอน้ำ (kgCO₂e/ตัน) = EF เชื้อเพลิง × ความร้อนต่อตันไอ ÷ η; NG ≈ 200–250, ถ่านหิน ≈ 350–400, ชีวมวล ≈ 0 (biogenic)

อัตราการนำคอนเดนเสทกลับ

ปริมาณไอน้ำผลิตเฉลี่ย (ตัน/ชม.) จาก steam meter/DCS หรือมิเตอร์น้ำป้อน
คอนเดนเสทที่กลับถังน้ำป้อน (ตัน/ชม.) จาก flow meter หรือประเมินจากน้ำเติม (= ไอน้ำ − น้ำเติม − blowdown)
อุณหภูมิคอนเดนเสทที่ถังรับ (°C) — วัดจริง 70–95 °C (ระบบเปิด), > 100 °C ถ้าเป็นระบบมีความดัน
อุณหภูมิน้ำเติมหลังปรับสภาพ (°C) — วัดจริง 25–32 °C
ค่าน้ำดิบ + ปรับสภาพ (softener/RO) + เคมี (บาท/ตัน) — ทั่วไป 25–60
ประสิทธิภาพหม้อไอน้ำจากผลตรวจวัด BS 845 (%) — 78–88 %

ตรวจ Waterlogging จาก ΔT คร่อมดัก

อุปกรณ์ที่ระบายคอนเดนเสทไม่ทันจะมีน้ำท่วมพื้นที่แลกเปลี่ยนความร้อน
อุณหภูมิผิวท่อก่อนเข้าดัก (°C) จาก IR/สัมผัส — ปกติใกล้ T_sat ที่ความดันอุปกรณ์
ความดันไอน้ำในอุปกรณ์แลกเปลี่ยนความร้อน (bar g) จากเกจอุปกรณ์
อุณหภูมิผิวท่อหลังดัก (°C) จาก IR — ดักปกติ ΔT คร่อมดัก 10–30 °C; ΔT ≈ 0 = รั่วผ่าน, ΔT มาก + ท่อก่อนดักเย็น = waterlogging
