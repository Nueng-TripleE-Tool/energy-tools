📐 สูตร / ที่มา

1) สมบัติอากาศชื้น

คำนวณด้วย engine กลาง TE_PSY ตาม ASHRAE Handbook—Fundamentals บทที่ 1 (Hyland–Wexler) ที่ความดันบรรยากาศ 101.325 kPa

  • W = 0.621945·pw/(p − pw) kg/kg อากาศแห้ง
  • h = 1.006·T + W·(2501 + 1.86·T) kJ/kg อากาศแห้ง
  • Tdp = อุณหภูมิที่ Pws(Tdp) = pw (จุดน้ำค้าง)

2) ผสมอากาศ (Mixing)

  • สมดุลมวล+พลังงาน: W_MA = x·W_OA + (1−x)·W_RA, h_MA = x·h_OA + (1−x)·h_RA
  • x = สัดส่วนลมใหม่ (โดยมวลอากาศแห้ง) → จุด MA อยู่บน เส้นตรง RA–OA ห่างจาก RA เป็นสัดส่วน x

3) คอยล์เย็น — ADP และ Bypass factor (BF)

  • ADP (Apparatus Dew Point) = อุณหภูมิผิวคอยล์เฉลี่ย อยู่บนเส้นอิ่มตัว
  • คอยล์เปียก: จุดหลังคอยล์อยู่บนเส้น MA→ADP h_CL = h_ADP + BF·(h_MA − h_ADP) (W เช่นกัน)
  • ADP ≥ Tdp ของลมเข้า → คอยล์แห้ง W คงที่ = sensible cooling (เส้นแนวนอน)
  • จุดเลยเส้นอิ่มตัว = หมอก/น้ำกลั่นในลม (fog) — ตรึงไว้บนเส้นอิ่มตัว

4) Reheat และพลังงาน

  • Reheat: W คงที่ T เพิ่ม (เส้นแนวนอนไปทางขวา)
  • Q_coil = ṁ_da·(h_MA − h_CL) · Q_reheat = ṁ_da·(h_SA − h_CL) (kW, ṁ เป็น kg/s)
  • น้ำกลั่น = ṁ_da·(W_MA − W_CL) · 1 TR = 3.517 kW · ละเทอม ṁw·hw ของน้ำทิ้ง (<1%)

5) สภาวะห้อง

  • h_R = h_SA + (Qs + Ql)/ṁ · W_R = W_SA + Ql/(ṁ·2501)
  • สมมติฐาน: steady state, ลมกลับ (RA) คงที่ตามค่าของด่าน, ไม่คิดความร้อนพัดลม/รั่วท่อ, BF คงที่

6) ลมใหม่ขั้นต่ำ ASHRAE 62.1 (ด่าน 5)

  • Vbz = Rp·Pz + Ra·Az ห้องเรียน (อายุ 9+): Rp = 5 L/s·คน, Ra = 0.6 L/s·m²
  • 41 คน, 70 m², Ez = 1.0 (จ่ายลมเย็นจากเพดาน) → Voz = 247 L/s → แปลงเป็นมวลด้วย v ของอากาศนอก
