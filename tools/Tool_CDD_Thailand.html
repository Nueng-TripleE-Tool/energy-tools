ดึงข้อมูลอุณหภูมิรายวัน (Fetch Daily Temperature)

ยังไม่มีข้อมูล — กดปุ่มดึงข้อมูล หรือโหลดไฟล์ JSON

หมายเหตุแหล่งข้อมูล: อุณหภูมิเฉลี่ยรายวัน (Tmean) จาก Open-Meteo Historical Weather API (ERA5/ERA5-Land reanalysis ของ ECMWF, กริด ~9–25 กม. ที่พิกัดศูนย์กลางจังหวัด) — ข้อมูลล่าช้าประมาณ 5 วัน จึงตั้งค่าเริ่มต้นถึงเดือนล่าสุดที่ครบเดือน · API ฟรีสำหรับการใช้งานที่ไม่ใช่เชิงพาณิชย์ขนาดใหญ่ (งานเชิงพาณิชย์ปริมาณมากควรสมัคร API plan) · ระบบแบ่งดึงเป็นรายปีเพื่อเลี่ยง rate limit — หากติด limit รายนาที (HTTP 429) เครื่องมือจะรอ ~1 นาทีแล้วดึงต่อเองอัตโนมัติ ไม่ต้องกดซ้ำ อย่าปิดหน้า · วิธีคำนวณ CDD ใช้ daily-mean method: CDDเดือน = Σ max(0, T̄วัน − Tbase) ซึ่งอาจต่างจาก degreedays.net (integration method จากข้อมูลรายชั่วโมง) เล็กน้อย โดยเฉพาะเดือนที่อุณหภูมิแกว่งใกล้ base temperature

คู่มือย่อ (Quick Guide)

① กด "ดึงข้อมูล" ขณะออนไลน์หนึ่งครั้ง (ประมาณ 10–30 วินาที) → ② บันทึก JSON ไว้ใช้ภาคสนามแบบ offline → ③ เลือกแท็บวิเคราะห์: รายจังหวัด / เปรียบเทียบ / แผนที่ / Regression กับข้อมูลพลังงาน (kWh) สำหรับงาน Energy Baseline ตาม ISO 50001 — ทุกแท็บเลือกชนิด CDD/HDD, กระเปาะแห้ง/เปียก และปรับ Base temperature ได้ −25 ถึง +35 °C (ละเอียด 1 °C และพิมพ์ค่าเองได้ เช่น −20 °C สำหรับห้องเย็น) · ปุ่มพิมพ์รายงานอยู่ท้ายแต่ละแท็บ (Ctrl+P ก็ได้)

CDD รายเดือน — รายจังหวัด

💡 ห้องเย็น: ตั้ง base = อุณหภูมิห้อง (เช่น −20 °C) แล้ว DD จะเท่ากับ ΔT·วัน ของกรอบห้องโดยตรง · หอผึ่งน้ำ: เลือกกระเปาะเปียก (Wet-bulb) เพราะเป็นตัวกำหนดสมรรถนะหอจริง

CDDเดือน = Σ max(0, T̄วัน − Tbase) · HDDเดือน = Σ max(0, Tbase − T̄วัน) หน่วย °C·day · เดือนที่ข้อมูลไม่ครบจะแสดงจำนวนวันกำกับ · T̄ = อุณหภูมิเฉลี่ยรายวันที่ 2 ม. จาก ERA5 · กระเปาะเปียกคำนวณจาก T̄ และ RH̄ รายวันด้วยสูตร Stull (2011) ความคลาดเคลื่อน ±0.3–1 °C ในย่าน RH 5–99% · ข้อควรระวัง: เมื่อ base ต่ำกว่าอุณหภูมิรายวันต่ำสุด (~15 °C) ทุกวันจะร่วมคำนวณหมด DD จะเทียบเท่า ΔT·วัน — เหมาะกับห้องเย็น/กระบวนการ sub-ambient แต่การ Optimize base ในย่านนี้จะแยกไม่ออก (R² แบนราบ) ให้กำหนด base = setpoint แทน

Regression: พลังงาน (kWh) vs CDD — Energy Baseline (ISO 50001)

กรอกข้อมูลรายเดือน — พลังงาน (kWh) และผลผลิต (ตัน, ไม่บังคับ)

วางค่าจาก Excel ได้: คัดลอกทั้งคอลัมน์แล้ววางในช่องแรกของคอลัมน์นั้น ระบบจะกระจายให้อัตโนมัติ (เรียงเดือนเก่า→ใหม่) · ถ้ากรอกผลผลิต ≥ 6 เดือน ระบบจะสลับเป็นแบบจำลอง 2 ตัวแปร E = a + b·ผลผลิต + c·DD อัตโนมัติ (เหมาะกับโรงงานที่ภาระขึ้นกับการผลิต เช่น โรงรีดเหล็ก)

แบบจำลอง OLS: E = a + b·DD (1 ตัวแปร) หรือ E = a + b·ผลผลิต + c·DD (2 ตัวแปร, เลือกอัตโนมัติเมื่อกรอกผลผลิต) · เกณฑ์ทั่วไปของ EnB ที่ใช้ได้ดี: R² ≥ 0.75 และสัมประสิทธิ์มีนัยสำคัญ (|t| ≥ 2) · CV(RMSE) ≤ 20% ตาม IPMVP · การ Optimize base ใช้ได้กับอาคารปรับอากาศ (balance point ในย่าน ~18–28 °C ตาม ASHRAE) — ห้องเย็น/กระบวนการ sub-ambient ให้กำหนด base = setpoint ตายตัว เพราะในย่านต่ำกว่าอุณหภูมิรายวันต่ำสุด R² จะแบนราบแยก base ไม่ออก · หอผึ่งน้ำใช้ DD กระเปาะเปียก (Wet-bulb) ร่วมกับผลผลิตเป็น 2 ตัวแปร
