สมการที่ใช้ (ASHRAE Handbook — Fundamentals, Ch.1 Psychrometrics)

ความดันไออิ่มตัว pws(T) : Hyland–Wexler (1983) — ASHRAE Eq. 5 & 6, T เป็นเคลวิน
ความดันบรรยากาศตามความสูง : p = 101.325 × (1 − 2.25577×10⁻⁵ Z)5.2559  [kPa, Z เป็นเมตร]

อัตราส่วนความชื้น   W = 0.621945 × pw / (p − pw)  [kg น้ำ / kg อากาศแห้ง]
ความชื้นสัมพัทธ์     RH = pw / pws(t) × 100 %
เอนทัลปี             h = 1.006 t + W (2501 + 1.86 t)  [kJ/kg อากาศแห้ง]
ปริมาตรจำเพาะ      v = 0.287042 (t + 273.15)(1 + 1.607858 W) / p  [m³/kg อากาศแห้ง]
ความหนาแน่นรวม   ρ = (1 + W) / v  [kg อากาศชื้น/m³]
กระเปาะเปียก (t ≥ 0 °C) : W = [(2501 − 2.326 t*)Ws* − 1.006(t − t*)] / (2501 + 1.86 t − 4.186 t*)
กระเปาะเปียก (t* < 0 °C) : W = [(2830 − 0.24 t*)Ws* − 1.006(t − t*)] / (2830 + 1.86 t − 2.1 t*)
ระดับความอิ่มตัว     μ = W / Ws(t)  ;  จุดน้ำค้าง : แก้สมการย้อน pws(Tdp) = pw

โหลดความร้อน   ṁda = V̇ / v  [kg อากาศแห้ง/s]
Qtotal = ṁda (h₁ − h₂)  ;  Qsensible = ṁda (1.006 + 1.86 W̄)(t₁ − t₂)  ;  Qlatent = Qtotal − Qsensible
SHR = Qsensible / Qtotal  ;  น้ำกลั่นตัว ṁw = ṁda(W₁ − W₂)  ;  1 TR = 3.51685 kW
การผสม : Wm = (ṁ₁W₁ + ṁ₂W₂)/(ṁ₁+ṁ₂) ; hm = (ṁ₁h₁ + ṁ₂h₂)/(ṁ₁+ṁ₂)

ค่าอ้างอิงที่ใช้บ่อยในงานตรวจวัด

  • สภาวะออกแบบภายในอาคารสำนักงานไทย: 25 °C DB, 55 % RH (บางกรณี 26 °C, 60 %)
  • สภาวะออกแบบภายนอก กรุงเทพฯ (ประมาณ 1 % design): 35 °C DB / 27 °C WB
  • อากาศออกจากคอยล์เย็นทั่วไป (off-coil): 12–14 °C DB, RH 90–95 %
  • อัตราอากาศภายนอกขั้นต่ำ ASHRAE 62.1 สำนักงาน: ≈ 8.5 L/s ต่อคน (2.5 L/s·คน + 0.3 L/s·m²)
  • ค่าประมาณเร็ว (ที่ 101.325 kPa, ρ ≈ 1.2 kg/m³): Qs ≈ 1.23 × L/s × ΔT (kW) ; Qt ≈ 1.20 × L/s × Δh (kW)
  • ในหอผึ่งเย็น (cooling tower) อากาศออกถือว่าอิ่มตัว RH ≈ 100 % — ใช้เครื่องมือนี้ประเมินอัตราการระเหยได้

ข้อจำกัด: สมการชุดนี้ใช้แบบจำลองก๊าซอุดมคติของอากาศชื้น (ASHRAE simplified) ให้ความคลาดเคลื่อน < 0.2 % ในช่วง −40 ถึง 100 °C ที่ความดันใกล้บรรยากาศ สำหรับความดันสูงหรืออุณหภูมิเกิน 120 °C ควรใช้แบบจำลองที่รวมค่า enhancement factor
