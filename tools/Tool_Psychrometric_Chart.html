1) สภาวะบรรยากาศ และค่าที่ตรวจวัดได้

ระบุความสูง = โปรแกรมคำนวณ P จากสมการบรรยากาศมาตรฐาน · ระบุตรง = ใช้ค่าจาก barometer/สถานีอุตุฯ (แม่นกว่าเมื่อทราบ)
กรุงเทพฯ ≈ 2 m · เชียงใหม่ ≈ 310 m · ภูเขา 1,000 m → 89.9 kPa
ความดันบรรยากาศสัมบูรณ์ที่ใช้คำนวณ (kPa) — เติมจากความสูงอัตโนมัติ หรือกรอกเอง · กรุงเทพฯ 100.8–101.5 kPa · ที่มา: barometer หน้างาน/กรมอุตุฯ

ป้อนค่าที่ทราบ 2 ค่า (เลือกคู่ที่ตรวจวัดได้)

เลือกคู่ค่าที่วัดได้จริง · เครื่องวัดดิจิทัล (testo 610/hygrometer) ให้ DB+RH · sling psychrometer ให้ DB+WB · dew-point meter ให้ DB+DP
ค่าแรกของคู่ที่เลือก (ปกติ = อุณหภูมิกระเปาะแห้ง °C) · อากาศภายนอกไทย 28–38 °C · ห้องปรับอากาศ 24–26 °C · ที่มา: thermo-hygrometer
ค่าที่สองของคู่ที่เลือก (RH % / WB °C / DP °C / W g/kg / h kJ/kg) · RH ภายนอกไทย 55–85 % · WB ออกแบบกรุงเทพฯ 28–29 °C · ที่มา: เครื่องวัดชนิดเดียวกัน

กระบวนการปรับอากาศ (Air Handling Process)

เลือกกระบวนการที่ต้องการวิเคราะห์ — คอยล์เย็น/ฮีตเตอร์/ผสมอากาศ/ระเหย/ฉีดไอน้ำ/อบแห้ง · แต่ละแบบเปลี่ยนช่องกรอกด้านล่างให้อัตโนมัติ
ความดันบรรยากาศสำหรับแท็บนี้ (kPa) — ควรใช้ค่าเดียวกับแท็บแรก

อากาศเข้า — สภาวะที่ 1 (Entering / Stream 1)

อุณหภูมิกระเปาะแห้งอากาศเข้า (°C) · อากาศกลับ (RA) 24–27 · อากาศภายนอก (OA) 30–36 · ที่มา: วัดที่ท่อลมกลับ/ช่องรับอากาศ
ความชื้นสัมพัทธ์อากาศเข้า (%) · RA 50–60 · OA 60–80 · ที่มา: thermo-hygrometer จุดเดียวกับ DB
อัตราการไหลอากาศเข้า (หน่วยตามที่เลือก) · AHU 1 RT ≈ 400 CFM ≈ 680 m³/h · ที่มา: balometer/anemometer × พื้นที่ท่อ หรือสเปคพัดลม
หน่วยของอัตราการไหล — m³/h (สเปคไทย/ยุโรป) · CFM (สเปคอเมริกา) · L/s · m³/min

อากาศออก — สภาวะที่ 2 (Leaving / Stream 2)

อุณหภูมิกระเปาะแห้งสภาวะที่ 2 (ทางออก/สาย 2) · off-coil 12–14 °C · หลังฮีตเตอร์ 35–60 °C · ที่มา: วัดหลังคอยล์ ~30 cm
ความชื้นสัมพัทธ์สภาวะที่ 2 · off-coil 90–95 % · ทางออกห้องอบ 20–40 % · ที่มา: thermo-hygrometer
อัตราการไหลสาย 2 (หน่วยเดียวกับสาย 1) — ใช้เฉพาะกระบวนการผสม · OA ทั่วไป 10–30 % ของลมจ่าย
ระเหย: ประสิทธิผลแผ่นทำความเย็น 0.70–0.90 (สเปคผู้ผลิต) · ไอน้ำ: อัตราฉีดไอน้ำ kg/h (สเปค humidifier/มิเตอร์ไอน้ำ)

แม่แบบ · หน่วย · ข้อมูลโครงการ (คลิกเพื่อเปิด/ปิด)

ต่อจุดสภาวะกับกระบวนการเป็นวงจรเดียว ส่งต่อมวลอากาศแห้ง ṁda ตลอดเส้นทาง แยกภาระคอยล์ ภาระห้อง และภาระลมภายนอก — ใช้ความดันบรรยากาศค่าเดียวกับแท็บแรก (101.325 kPa)

เลือกแม่แบบแล้วกรอกค่าด้านล่าง กด "สร้างวงจร" — หลังสร้างแก้ไข ลากจุด เพิ่ม/ลบกระบวนการได้ทุกตัว
เปลี่ยนเฉพาะการแสดงผลและช่องกรอกในตัวแก้ไข — ภายในคำนวณเป็น SI เสมอ · ช่องกรอกของแม่แบบเป็น SI

    สำนักงาน 50–60 % · ห้องเก็บยา ≤ 60 % · ห้องอิเล็กทรอนิกส์ 45 ± 5 %
    สร้างจุดสภาวะจากค่าเฉลี่ย DB/W ของข้อมูลที่วางไว้ เพื่อใช้ต่อกระบวนการ
    ขอบเขต PMV −0.5 ถึง +0.5 (PPD ≤ 10 %) ตาม ASHRAE 55 · สมมติอุณหภูมิผิวรอบตัว (MRT) = DB · 0.5 clo = เสื้อเชิ้ตแขนสั้น-กางเกงขายาว
    นั่งทำงานเอกสาร 1.0–1.1 · ยืนทำงานเบา 1.4–1.6 · เดินไปมา 1.7–2.0 (ใช้ได้ 1.0–2.0)
    ห้องปรับอากาศทั่วไป 0.1–0.2 m/s · วิธี PMV ใช้ได้ถึง 0.2 m/s (เกินนั้นต้องใช้ SET/elevated air speed)
    ฉบับใหม่ไม่บังคับเพดานความชื้น แต่ในไทยควรคุม W ≤ 12 g/kg เพื่อกันเชื้อราและความรู้สึกเหนียวตัว
    คัดลอกสองคอลัมน์สุดท้าย (DB °C, RH %) จาก Excel/CSV ของ logger (testo 174H, HOBO, Elitech) — ข้อมูลไม่ถูกส่งออกจากเครื่อง · หน่วย DB ตามระบบหน่วยที่เลือก

    สมการที่ใช้ (ASHRAE Handbook — Fundamentals, Ch.1 Psychrometrics)

    ความดันไออิ่มตัว pws(T) : Hyland–Wexler (1983) — ASHRAE Eq. 5 & 6, T เป็นเคลวิน
    ความดันบรรยากาศตามความสูง : p = 101.325 × (1 − 2.25577×10⁻⁵ Z)5.2559  [kPa, Z เป็นเมตร]

    อัตราส่วนความชื้น   W = 0.621945 × pw / (p − pw)  [kg น้ำ / kg อากาศแห้ง]
    ความชื้นสัมพัทธ์     RH = pw / pws(t) × 100 %
    เอนทัลปี             h = 1.006 t + W (2501 + 1.86 t)  [kJ/kg อากาศแห้ง]
    ปริมาตรจำเพาะ      v = 0.287042 (t + 273.15)(1 + 1.607858 W) / p  [m³/kg อากาศแห้ง]
    ความหนาแน่นรวม   ρ = (1 + W) / v  [kg อากาศชื้น/m³]
    กระเปาะเปียก (t ≥ 0 °C) : W = [(2501 − 2.326 t*)Ws* − 1.006(t − t*)] / (2501 + 1.86 t − 4.186 t*)
    กระเปาะเปียก (t* < 0 °C) : W = [(2830 − 0.24 t*)Ws* − 1.006(t − t*)] / (2830 + 1.86 t − 2.1 t*)
    ระดับความอิ่มตัว     μ = W / Ws(t)  ;  จุดน้ำค้าง : แก้สมการย้อน pws(Tdp) = pw

    โหลดความร้อน   ṁda = V̇ / v  [kg อากาศแห้ง/s]
    Qtotal = ṁda (h₁ − h₂)  ;  Qsensible = ṁda (1.006 + 1.86 W̄)(t₁ − t₂)  ;  Qlatent = Qtotal − Qsensible
    SHR = Qsensible / Qtotal  ;  น้ำกลั่นตัว ṁw = ṁda(W₁ − W₂)  ;  1 TR = 3.51685 kW
    การผสม : Wm = (ṁ₁W₁ + ṁ₂W₂)/(ṁ₁+ṁ₂) ; hm = (ṁ₁h₁ + ṁ₂h₂)/(ṁ₁+ṁ₂)

    ค่าอ้างอิงที่ใช้บ่อยในงานตรวจวัด

    • สภาวะออกแบบภายในอาคารสำนักงานไทย: 25 °C DB, 55 % RH (บางกรณี 26 °C, 60 %)
    • สภาวะออกแบบภายนอก กรุงเทพฯ (ประมาณ 1 % design): 35 °C DB / 27 °C WB
    • อากาศออกจากคอยล์เย็นทั่วไป (off-coil): 12–14 °C DB, RH 90–95 %
    • อัตราอากาศภายนอกขั้นต่ำ ASHRAE 62.1 สำนักงาน: ≈ 8.5 L/s ต่อคน (2.5 L/s·คน + 0.3 L/s·m²)
    • ค่าประมาณเร็ว (ที่ 101.325 kPa, ρ ≈ 1.2 kg/m³): Qs ≈ 1.23 × L/s × ΔT (kW) ; Qt ≈ 1.20 × L/s × Δh (kW)
    • ในหอผึ่งเย็น (cooling tower) อากาศออกถือว่าอิ่มตัว RH ≈ 100 % — ใช้เครื่องมือนี้ประเมินอัตราการระเหยได้

    ข้อจำกัด: สมการชุดนี้ใช้แบบจำลองก๊าซอุดมคติของอากาศชื้น (ASHRAE simplified) ให้ความคลาดเคลื่อน < 0.2 % ในช่วง −40 ถึง 100 °C ที่ความดันใกล้บรรยากาศ สำหรับความดันสูงหรืออุณหภูมิเกิน 120 °C ควรใช้แบบจำลองที่รวมค่า enhancement factor
