📐 สูตร / ที่มา

1) Regression แบบ OLS (Ordinary Least Squares)

E = a + b₁·x₁ + b₂·x₂ + … + ε
β = (XᵀX)⁻¹ Xᵀy — เส้นที่ทำให้ SSE = Σ(y − ŷ)² ต่ำที่สุด

2) ความเหมาะสมของโมเดล

R² = 1 − SSE/SST  ·  adj R² = 1 − (1−R²)(n−1)/(n−p)
RMSE = √(SSE/(n−p))  ·  CV(RMSE) = RMSE/ȳ × 100%
  • n = จำนวนเดือน, p = จำนวนพารามิเตอร์ (รวมค่าคงที่ a)
  • ASHRAE Guideline 14: ข้อมูลรายเดือน CV(RMSE) ≤ 15% และ NMBE ≤ ±5% (OLS ให้ NMBE = 0 ในช่วง baseline เสมอ)

3) ความมีนัยสำคัญของแต่ละตัวแปร

SE(bⱼ) = √(s²·[(XᵀX)⁻¹]ⱼⱼ), s² = SSE/(n−p)
t = bⱼ / SE(bⱼ)  ·  p-value จาก t-distribution (df = n−p)
  • กฎหัวแม่มือ |t| > 2 ≈ p < 0.05 → ตัวแปรช่วยอธิบายจริง
  • adj R² จะ "ลดลง" เมื่อเพิ่มตัวแปรที่ |t| < 1

4) Cooling Degree Days

CDD(Tb) = Σวัน max(0, Tเฉลี่ยวัน − Tb)
  • Tb ≈ balance point ของอาคาร — เลือกค่าที่ให้ R² สูงสุด (ISO 50006 ภาคผนวก)

5) CUSUM และผลประหยัด

CUSUMₖ = Σi≤k (Eจริง − Eคาดการณ์จาก baseline)
ผลประหยัดสะสม = Σ(Eคาดการณ์ − Eจริง) = −CUSUM ปลายช่วง
  • ความชันของ CUSUM เปลี่ยน = สมรรถนะเปลี่ยน (มาตรการเริ่มผล / เครื่องเสื่อม)
  • IPMVP Option C (ทั้งโรงงาน) · ISO 50015 (M&V) · ISO 50006 (EnB/EnPI)

สมมติฐานของเกม

  • ข้อมูลสังเคราะห์: E = a + b·ผลผลิต + c·CDD + สัญญาณรบกวนแบบปกติ (seed คงที่ต่อด่าน)
  • อุณหภูมิรายวันจำลองจากค่าเฉลี่ยรายเดือนเชียงใหม่ (ด่าน 2) / ภาคกลาง (ด่าน 3, 5)
  • ตัวเลขอยู่ในช่วงโรงงานอาหารขนาดกลาง 0.3–0.6 GWh/เดือน และอาคารสำนักงาน 70–190 MWh/เดือน
