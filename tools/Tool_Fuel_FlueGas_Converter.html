ข้อมูลเชื้อเพลิง

เลือกจากคลังเพื่อเติมค่าตั้งต้น แล้วแก้เป็นค่าของล็อตจริงได้ทุกช่อง
เลือกจากคลังเพื่อเติมค่าตั้งต้น (LHV as-received, ρ, η) — เลือก "กำหนดเอง" เมื่อมีผลวิเคราะห์ของล็อตจริง
ค่าความร้อนต่ำ (LHV, as-received) ของล็อตที่ซื้อจริง · ที่มา: ใบรับรองผลวิเคราะห์ (COA) / ห้องแล็บ · ค่าทั่วไป: ไม้สับชื้น 40 % 10–12, PKS 16–17, บิทูมินัส 24–27 MJ/kg, NG 35–38 MJ/Nm³
ต้องตรงกับหน่วยในเอกสารแล็บ — kcal/kg ×0.004187 = MJ/kg · Btu/lb ×0.002326 = MJ/kg · ก๊าซใช้ MJ/Nm³ หรือ MJ/Sm³
ใช้เมื่อราคาเป็นต่อปริมาตร (บาท/L, บาท/m³) แต่ค่าความร้อนเป็นต่อมวล · น้ำมันเตา 0.94–0.98 kg/L · ดีเซล 0.83–0.85 · LPG เหลว 0.52–0.55 · NG 0.72–0.80 kg/Nm³ · ใส่ 0 ถ้าไม่ต้องแปลง
kg/L สำหรับของเหลว/ของแข็ง (bulk density) · kg/Nm³ สำหรับก๊าซที่ 0 °C
ฐานอุณหภูมิของ Sm³ ที่ผู้ขายก๊าซใช้ — ผู้จำหน่ายก๊าซในไทยใช้ 15.56 °C (60 °F) · ISO 13443 ใช้ 15 °C · Nm³ = 0 °C เสมอ
Nm³ กับ Sm³ ไม่เท่ากัน — Nm³ อ้างอิงที่ 0 °C ส่วน Sm³ อ้างอิงที่อุณหภูมิสูงกว่า ก๊าซ 1 Sm³ จึงมีจำนวนโมลน้อยกว่า 1 Nm³ และให้พลังงานน้อยกว่าตามอัตราส่วน 273.15/(273.15 + t) ที่ 15 °C คิดเป็น 0.9479 เท่า — ถ้าสลับสองหน่วยนี้จะคลาดเคลื่อนราว 5 %

ราคาที่ซื้อจริง

ราคาซื้อจริงรวม VAT/ค่าขนส่งถึงโรงงาน · ที่มา: ใบแจ้งหนี้/สัญญาซื้อขาย · ปี 2569 โดยประมาณ: PKS 2,500–3,200 บาท/ตัน · ไม้สับ 900–1,300 · น้ำมันเตา 20–25 บาท/L · NG 350–450 บาท/MMBtu
เลือกให้ตรงกับใบแจ้งหนี้ — โปรแกรมแปลงเป็นบาท/GJ และบาท/MJ อัตโนมัติ
ใช้เฉพาะเมื่อหน่วยราคาเป็น บาท/MMBTU (ทั้งแท็บ 1 และตารางเปรียบเทียบ) — ราคา NG จากผู้จำหน่ายเป็นฐาน GCV ขณะที่ค่าความร้อนและ η ในเครื่องมือนี้เป็นฐาน LHV ต้องคูณ HHV/LHV จึงเทียบกันได้
NG ไทย ~1.109 (1,008/908.6 BTU/SCF ใบวิเคราะห์อ้างอิง) · LPG ~1.08 · น้ำมันเตา ~1.06 — ใช้ค่าจากใบวิเคราะห์ก๊าซถ้ามี
ประสิทธิภาพอุปกรณ์ที่ใช้เชื้อเพลิงนี้ (ฐาน LHV) · หม้อไอน้ำชีวมวล 70–82 % · ถ่านหิน 80–86 % · น้ำมัน/ก๊าซ 85–92 % · ที่มา: ผลตรวจวัดจริงหรือค่าประกันของผู้ผลิต

ตารางราคาในทุกหน่วย

ค่าที่แปลงได้จากข้อมูลที่ใส่ — ช่องที่เป็น “–” แปลว่ายังขาดความหนาแน่นหรือค่าความร้อนในฐานนั้น

เปรียบเทียบต้นทุนความร้อนของเชื้อเพลิงหลายชนิด

เทียบบนฐานเดียวกันคือ บาทต่อ GJ ความร้อนที่ใช้งานได้จริง หลังหักประสิทธิภาพอุปกรณ์แล้ว — นี่คือฐานเดียวที่เทียบข้ามเชื้อเพลิงได้อย่างเป็นธรรม

แปลง LHV ↔ HHV

ผลต่างมาจากความร้อนแฝงของน้ำที่เกิดจากไฮโดรเจนในเชื้อเพลิงและความชื้นที่ติดมา
LHV→HHV เมื่อมีผลแล็บเป็น LHV (Net) · HHV→LHV เมื่อผลแล็บเป็น HHV (Gross, bomb calorimeter) — โรงงานไทยส่วนใหญ่ได้ HHV จากแล็บ
ค่าความร้อนที่ต้องการแปลง (MJ/kg) — เติมจากแท็บ 1 อัตโนมัติ พิมพ์ทับได้เมื่อมีผลแล็บของล็อตจริง
ฐานของค่าที่ใส่: as-received (ar) = ตามที่รับจริง · dry = ฐานแห้ง · daf = ฐานแห้งไร้เถ้า — อ่านจากหัวตารางในผลวิเคราะห์
ไฮโดรเจนในเชื้อเพลิง ฐานแห้ง (ultimate analysis) · ชีวมวล 5.5–6.5 % · ถ่านหิน 4–5.5 % · น้ำมันเตา 11–12 % · ที่มา: ผลแล็บ ASTM D5373 / ค่าจากคลัง
ความชื้นรวมตามที่รับจริง (total moisture, ar) · ไม้สับ 35–50 % · แกลบ 8–12 % · PKS 10–15 % · ทะลายปาล์ม 55–65 % · ที่มา: ASTM E871 / วัดหน้างานด้วย moisture meter
เถ้า ฐานแห้ง (proximate analysis) · แกลบ 15–20 % · ไม้สับ 1–3 % · ถ่านหิน 8–15 % · ที่มา: ASTM D3174 / ผลแล็บ

ปริมาณเชื้อเพลิง ↔ พลังงาน

ใช้ค่าความร้อนและความหนาแน่นจากแท็บที่ 1
ปริมาณเชื้อเพลิงที่ต้องการแปลงเป็นพลังงาน · ที่มา: ใบชั่ง/ใบส่งของ/มิเตอร์ก๊าซ
หน่วยของปริมาณ — ต้องมีค่าความร้อนหรือความหนาแน่นในฐานที่แปลงถึงกันได้ (ดูแท็บ 1)
ชั่วโมงที่ใช้ปริมาณนี้ (เพื่อคิดอัตรา MW, kg/h) · ใส่ 0 ถ้าไม่ต้องการอัตรา · เช่น 1 กะ = 8 ชม., 1 เดือน ≈ 720 ชม.

แก้ค่ามลพิษไปที่ O₂ อ้างอิง

ความเข้มข้นมลพิษที่วัดได้ (mg/Nm³ หรือ ppm หน่วยเดียวกับผลลัพธ์) · ที่มา: CEMS / เครื่องวิเคราะห์ก๊าซแบบพกพา / รายงานตรวจวัดปล่อง
O₂ ในไอเสียขณะวัด ฐานแห้ง · ที่มา: เครื่องวิเคราะห์ก๊าซ/CEMS อ่านพร้อมกับค่ามลพิษ · ชีวมวล 6–10 % · ก๊าซ 3–5 % · ถ่านหิน 5–7 %
O₂ อ้างอิงตามกฎหมาย — หม้อไอน้ำเชื้อเพลิงแข็ง/ชีวมวล 7 % · เชื้อเพลิงเหลว/ก๊าซ 3 % (ประกาศ ทส.) · เตาเผาขยะ 11 % · ก๊าซเทอร์ไบน์ 15 %

แปลง ppm ↔ mg/Nm³

เลือกก๊าซเพื่อใช้มวลโมเลกุลในการแปลง ppm ↔ mg/Nm³ · NOx รายงานเป็น NO₂ (MW 46.01) ตามกฎหมายไทย
ค่าที่อ่านจากเครื่องมือ · เครื่องวิเคราะห์ก๊าซแบบพกพาให้ ppm · CEMS หรือรายงานราชการมักเป็น mg/Nm³
หน่วยของค่าที่ใส่ — ผลลัพธ์จะแสดงอีกหน่วยที่ 0 °C, 101.325 kPa

ไอเสียฐานแห้ง ↔ ฐานเปียก

ความเข้มข้นที่มีอยู่ (หน่วยใดก็ได้ — โปรแกรมคูณ/หารด้วยสัดส่วนไอน้ำ)
เครื่องมือชนิด extractive มี cooler → อ่านค่าเป็นฐานแห้ง · in-situ/hot-wet → ฐานเปียก · มาตรฐานไทยรายงานฐานแห้ง
ไอน้ำในไอเสีย % ปริมาตร · ก๊าซธรรมชาติ 15–19 % · น้ำมันเตา 9–12 % · ถ่านหิน 6–9 % · ชีวมวลชื้น 15–25 % · วัดด้วย CEMS H₂O หรือคำนวณจาก H และ M ของเชื้อเพลิง
