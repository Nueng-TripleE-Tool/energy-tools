พื้นที่ผิวที่แสดงคือ พื้นที่ผิวโค้งด้านนอกที่ใช้ถ่ายเทความร้อน (Curved / Heat-transfer surface area) · D = เส้นผ่านศูนย์กลาง, H/L = ความสูงหรือความยาว, h = ความลึกหัวถัง

สมการที่ใช้

1) ความต้านทานความร้อนอนุกรม
Q = (Tf − Ta) / (Ri + Rผนัง + Rฉนวน + Rหุ้มนอก + Ro)
Ri = 1/(hi·Ain)  ;  Ro = 1/(ho·Aout)  ;  Rชั้น = t / (k · Amean)
Amean : ผิวราบ = A  | ทรงกระบอก = (A₂−A₁)/ln(A₂/A₁) (log-mean)  | ทรงกลม/หัวถัง = √(A₁·A₂) (geometric-mean)

2) สัมประสิทธิ์ผิวนอก ho = hc + hr  (ISO 12241 Annex A)
การพาอิสระ — ผนังตั้ง:   hc = 1.32(ΔT/H)0.25 [laminar, H³ΔT<10] ; 1.31·ΔT1/3 [turbulent]
การพาอิสระ — ทรงกระบอกนอน: hc = 1.25(ΔT/D)0.25 ; 1.21·ΔT1/3
การพาอิสระ — ผิวราบหันขึ้น: hc = 1.32(ΔT/L)0.25 ; หันลง: hc = 0.59(ΔT/L)0.25
การพาบังคับ (มีลม v ≥ 0.5 m/s): hc = 8.9·v0.9 / D0.1
การแผ่รังสี: hr = ε·σ·(Ts⁴ − Ta⁴)/(Ts − Ta) , σ = 5.67×10⁻⁸ W/m²K⁴ , T เป็นเคลวิน
แก้สมการซ้ำ (iteration) หา Ts จนลู่เข้า เพราะ ho ขึ้นกับ Ts

3) ค่าการนำความร้อนของฉนวนขึ้นกับอุณหภูมิ
k(Tm) = a + b·Tm + c·Tm² , Tm = อุณหภูมิเฉลี่ยของฉนวน = (Tผิวใน + Tผิวนอก)/2

4) เศรษฐศาสตร์
พลังงานสูญเสีย = Q(kW) × ชั่วโมงต่อปี  →  เชื้อเพลิง = พลังงาน / (LHV/3.6 × η)
ค่าฉนวนรายปี = (ต้นทุนติดตั้ง) × CRF , CRF = i(1+i)n / [(1+i)n − 1]
ความหนาที่เหมาะสม = จุดที่ (ค่าพลังงานสูญเสีย + ค่าฉนวนรายปี) ต่ำสุด

เกณฑ์ตรวจสอบภาคสนาม

  • อุณหภูมิผิวสัมผัสปลอดภัย: ASTM C1055 กำหนดผิวโลหะที่ 60 °C สัมผัส 5 วินาที = ขีดเริ่มบาดเจ็บ — งานตรวจวัดพลังงานไทยใช้เกณฑ์ผิวฉนวนไม่เกิน 60 °C (บริเวณที่คนเข้าถึงได้)
  • ตรวจด้วยกล้องถ่ายภาพความร้อน: เทียบ Ts ที่คำนวณกับที่วัดจริง ต่างเกิน 10 °C แสดงว่าฉนวนเสื่อม/เปียก หรือมี thermal bridge
  • จุดที่มักถูกลืมหุ้ม: หน้าแปลน วาล์ว ขาถัง แมนโฮล ช่องมองระดับ หัวถังบน–ล่าง — ใช้รูปทรง “พื้นที่ผิวกำหนดเอง” เพิ่มเข้าไป
  • งานเย็น (cold service): ต้องตรวจว่า Ts สูงกว่าจุดน้ำค้างของอากาศ มิฉะนั้นเกิดหยดน้ำและ CUI — ใช้เครื่องมือ Psychrometric Chart หาจุดน้ำค้าง
  • ข้อจำกัด: สมการนี้เป็นการถ่ายเทความร้อน 1 มิติต่อชิ้น ไม่รวม thermal bridge จากขาตั้ง/หูยก/nozzle ในทางปฏิบัติควรบวกเผื่อ 5–15 % ของค่าที่คำนวณได้
