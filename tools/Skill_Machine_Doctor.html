📐 สูตร / ที่มา

1) เกณฑ์ความสั่นสะเทือน ISO 10816-3

เครื่องกลุ่ม 2 (15–300 kW) ฐานแข็ง (rigid) · velocity rms ย่าน 10–1,000 Hz · (ฉบับใหม่ ISO 20816-3 ใช้ค่าใกล้เคียงกัน)

โซนmm/s rmsความหมาย
A< 1.4เครื่องใหม่/ดีมาก
B1.4 – 2.8เดินต่อได้ระยะยาว
C2.8 – 4.5เดินได้จำกัด วางแผนซ่อม
D> 4.5อันตราย เสี่ยงเสียหาย
V_overall = √( Σ a_i² + a_floor² )

2) อ่านสเปกตรัม (ความถี่ = อันดับ × รอบเพลา)

f1 = rpm / 60 (1460 rpm → 24.3 Hz = 1×)
  • 1× เด่น แนวรัศมี (H≈V) แกนต่ำ → unbalance
  • 2× สูง + แนวแกน (A) สูง → misalignment
  • 1× + ฮาร์มอนิก 2×–6× แนวดิ่งเด่น → soft foot/ฐานหลวม
  • ความถี่ไม่ลงตัว (3.03×, 6.07×…) + ย่านสูงยกตัว → แบริ่ง
  • peak ต่ำกว่า 1× (0.4×, 0.8×) → สายพาน
  • สัญญาณกว้าง ๆ ย่านสูง + vane pass (6×) → cavitation
BPFO = (n/2)·f1·(1 − d/D·cosθ)

แบริ่ง 6309: n = 8 ลูก, d = 17.5 mm, D = 72.5 mm → BPFO ≈ 3.03× · BPFI ≈ 4.97× (คร่าว ๆ BPFO ≈ 0.4·n·f1)

f_belt = π·D_pulley·n / (60·L)

มู่เล่ย์ 200 mm @1460 rpm, สายพานยาว 2.5 m → 6.1 Hz (≈ 0.41× ของรอบพัดลม)

3) Cavitation — NPSH

NPSHa = (P_atm − P_v)/ρg + h_s − h_f > NPSHr + margin

น้ำ 35 °C: P_v = 5.63 kPa · h_s = +2 m (ถังสูงกว่าปั๊ม) · ปกติ h_f = 0.8 m → NPSHa = 11.0 m
วาล์วดูดหรี่จน h_f = 8 m → NPSHa = 3.8 m < NPSHr 4.5 m → ฟองไอแตก = เสียงกรวด · เกจดูด ≈ −0.60 bar g

4) กระแส 3 เฟสไม่สมดุล (NEMA MG-1)

%Unbal = |I − I_avg|max / I_avg × 100 ≤ 10%

แรงดันไม่สมดุล 1% ทำกระแสไม่สมดุล ~6–10% · ขดลวดร้อนเพิ่ม ≈ 2×(%V_unb)² % · ไฟขาดเฟส (single-phasing) = เฟสหนึ่ง 0 A อีกสองเฟสพุ่ง ~1.7 เท่า

P_in = √3 · V · I · PF

5) อุณหภูมิ & ไส้กรอง

  • แบริ่ง (อากาศรอบ 35 °C): ปกติ ≤ 70 °C · เฝ้าระวัง 70–80 · > 80 °C ผิดปกติ
  • ขั้วสาย/กล่องต่อสาย: ร้อนกว่าเฟสอื่นหรือ > 60 °C = ขั้วหลวม/ออกไซด์
  • ไส้กรองพัดลม: ใหม่ ~150 Pa เปลี่ยนที่ ~300 Pa (≈2 เท่า) · กรองอากาศคอมเพรสเซอร์: เตือนที่ 50 mbar
  • ไส้กรองตัน → ลม/อากาศไหลน้อยลง → กระแสลดลง (ไม่ใช่เพิ่ม) แต่ประสิทธิภาพแย่ลง
  • พัดลม: กำลัง ∝ n³ → สายพานลื่น 980→905 rpm กำลังเหลือ ~79%

ตัวเลขในเกมสร้างจากสูตรข้างต้นและค่าที่พบบ่อยในโรงงาน ใช้เพื่อการฝึก — หน้างานจริงให้ดูเทรนด์เทียบค่าเดิมของเครื่องเสมอ
