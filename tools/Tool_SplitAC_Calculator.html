🌬️ Split Type AC — Performance & Efficiency Analysis
❄️
1. EER / COP / SEER
ประสิทธิภาพตาม Nameplate, คำนวณ SEER, เปรียบเทียบมาตรฐาน TISI 1309 และ ECBC
EER = Q_cool(BTU/hr) / W(W) COP = Q_cool(kW) / W(kW) SEER = ΣQ_season / ΣW_season
🔬
2. Field Measurement
วัดจริงภาคสนาม: V, I, PF, DB/WB อากาศเข้า-ออก — คำนวณ Q_sens, Q_lat, SHR, COP_field
Q_sens = ṁ×Cp×ΔT_db Q_lat = ṁ×Δω×2501 COP_f = Q_total / W_input
🧊
3. Refrigerant & SH/SC
วิเคราะห์วงจรสาร, Superheat, Subcooling, Compression Ratio — วินิจฉัยปัญหาระบบ
SH = T_suction − T_sat(evap) SC = T_sat(cond) − T_liquid CR = P_cond / P_evap
🏠
4. Cooling Load & Sizing
ประเมิน Cooling Load ห้อง, ตรวจสอบขนาด AC ที่เหมาะสม (Over/Under sizing)
Q_wall = U×A×CLTD Q_solar= SC×A×SHGF×CLF Q_occ = N×sensible_person
📊
5. เปรียบเทียบ & สรุป
Nameplate vs Field, มูลค่าพลังงานสูญเสีย, ข้อเสนอแนะ และ Annual Cost Analysis
Degradation = ΔCOP/COP_rated Saving = ΔW × hrs × tariff ROI = Cost_invest / Annual_save
