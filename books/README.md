# คลังหนังสือ (E-Book) — Energy Engineering Tools

ระบบอ่านหนังสือออนไลน์แบบ **อ่านอย่างเดียว** สำหรับเว็บ energy-tools
ไม่มีปุ่มดาวน์โหลด ไม่มีปุ่มสั่งพิมพ์ และไม่มี text layer ให้คัดลอก

---

## โครงสร้างโฟลเดอร์

```
books/
├── reader.html              ← ตัวอ่าน ใช้ร่วมกันทุกเล่ม (ไม่ต้องแก้)
├── README.md                ← ไฟล์นี้
├── _tools/
│   └── pack_book.py         ← สคริปต์แปลง Word/PDF เป็นหนังสือ
└── <slug>/                  ← หนึ่งโฟลเดอร์ต่อหนึ่งเล่ม
    ├── book.eeb             ← เนื้อหาที่ผ่านการ obfuscate แล้ว
    ├── book.json            ← ชื่อ ผู้แต่ง จำนวนหน้า สารบัญ
    ├── search.json          ← ดัชนีค้นหา (ทำให้ค้นในเล่มหนาได้ทันที)
    └── cover.webp           ← ภาพปกจากหน้าแรก
```

เปิดอ่านที่ `books/reader.html?b=<slug>`

## ขั้นตอนเพิ่มหนังสือใหม่

### 1. แปลงไฟล์ต้นฉบับ

```bash
cd books/_tools
python pack_book.py "D:\Docs\คู่มือปรับแต่งการเผาไหม้.docx" ^
       --slug solid-fuel-tuning ^
       --title "คู่มือการปรับแต่งการเผาไหม้เชื้อเพลิงแข็ง" ^
       --subtitle "Solid Fuel Combustion Tuning Manual" ^
       --author "อ.หนึ่ง กลับทวี" ^
       --category thermal ^
       --desc "แนวทางปรับแต่งการเผาไหม้ถ่านหินและชีวมวลสำหรับงานตรวจวัดหน้างาน" ^
       --tags "ถ่านหิน,ชีวมวล,chain grate,อากาศส่วนเกิน"
```

รับได้ทั้ง `.docx` (ต้องมี LibreOffice) และ `.pdf`

### 2. เพิ่มการ์ดใน `index.html`

คัดลอกบล็อก `<div class="tool-card">` ในกลุ่ม **Knowledge Library** แล้วแก้
ชื่อเล่ม / คำอธิบาย / จำนวนหน้า / path ของปก / `?b=<slug>` / `id="count-bk_xxx"`

### 3. เพิ่ม key ใน `TOOL_KEYS` (ท้ายไฟล์ `index.html`)

```js
bk_solidfuel: 'Book_solid-fuel-tuning'
```

ให้ตรงกับทั้ง `id="count-bk_solidfuel"` และ `onclick="trackOpen('bk_solidfuel')"`

### 4. อัปเดตตัวเลข `gh-count` ของกลุ่ม (เช่น `2 Books`)

## สารบัญ (TOC)

* ถ้าไฟล์ PDF ต้นฉบับมี bookmark สคริปต์จะดึงมาให้อัตโนมัติ
  (Word: ใช้ Heading 1/2/3 แล้ว export PDF โดยติ๊ก "สร้างบุ๊กมาร์กโดยใช้หัวเรื่อง")
* ถ้าไม่มี สามารถแก้ `toc` ใน `book.json` เองได้ รูปแบบ:

```json
"toc": [
  { "title": "บทที่ 1 — บทนำ", "page": 5,  "level": 1 },
  { "title": "1.1 ขอบเขต",     "page": 7,  "level": 2 }
]
```

สารบัญที่แก้เองจะถูกเก็บไว้ ไม่หายเมื่อ `pack_book.py` รันซ้ำ (ถ้า PDF ไม่มี bookmark)

## เพดานการใช้งานจริง

| หัวข้อ | ค่าที่ทดสอบแล้ว | ขีดจำกัดที่แนะนำ |
|---|---|---|
| จำนวนหน้า | 600 หน้า เปิดหน้าแรกได้ใน ~1 วินาที | ถึง ~1,500 หน้าต่อเล่ม |
| หน่วยความจำ | คงที่ ~28 MB ไม่ว่าจะเลื่อนกี่หน้า | — (ระบบรีไซเคิล canvas เก็บไว้ 12 หน้า) |
| ค้นหาทั้งเล่ม | 600 หน้า ได้ผลทันทีจาก `search.json` | — |
| ขนาดไฟล์ | ต้องโหลดทั้งเล่มก่อนเปิดหน้าแรก | ไม่ควรเกิน **60 MB** ต่อเล่ม |

ถ้าเล่มใหญ่เกิน 60 MB (ปกติคือมีรูปถ่ายเยอะ) มี 2 ทางเลือก:

1. ลดความละเอียดรูปก่อน export PDF (150 dpi เพียงพอสำหรับอ่านบนจอ)
2. แยกเป็นเล่มย่อย เช่น `solid-fuel-tuning-1`, `solid-fuel-tuning-2`
   แล้วทำเป็น 2 การ์ดในหน้าแรก

## มาตรการป้องกัน

| มาตรการ | ผล |
|---|---|
| ไม่มีปุ่มดาวน์โหลด/พิมพ์ ใน UI | ผู้ใช้ทั่วไปหาทางโหลดไม่เจอ |
| ไฟล์เก็บเป็น `.eeb` ที่ผ่าน XOR keystream | เปิด URL ตรง ๆ ได้แต่ไฟล์ใช้งานไม่ได้ |
| Render เป็น canvas ไม่มี text layer | เลือก/คัดลอกข้อความไม่ได้ |
| `@media print { * { display:none } }` | สั่งพิมพ์ได้แต่ออกมาหน้าว่าง |
| ดัก `Ctrl+P` / `Ctrl+S` / `Ctrl+U` / `F12` / คลิกขวา / ลากภาพ | พร้อมข้อความแจ้งเตือน |
| ลายน้ำฝังลงใน canvas ทุกหน้า | ติดไปกับ screenshot ด้วย |

**ข้อจำกัดที่ต้องรู้:** ระบบนี้เป็น *การเพิ่มความยาก* ไม่ใช่ DRM
ผู้ใช้ที่มีความรู้ยังสามารถดึงเนื้อหาผ่าน DevTools หรือถ่ายภาพหน้าจอได้
การป้องกันระดับ 100% ต้องมี server ตรวจสอบสิทธิ์รายบุคคล ซึ่งเว็บ static ทำไม่ได้

## หมายเหตุ

* ต้องเปิดผ่าน **http/https** (GitHub Pages หรือ local server) — เปิดจาก `file://` ตรง ๆ ไม่ได้ เพราะเบราว์เซอร์บล็อก `fetch`
* ทดสอบในเครื่องด้วย `python -m http.server 8000` แล้วเปิด `http://localhost:8000/books/reader.html?b=<slug>`
* สถิติการเปิดอ่านใช้ Cloudflare Worker ตัวเดียวกับเครื่องมืออื่น key ขึ้นต้นด้วย `Book_`
